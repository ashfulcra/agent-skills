# fulcra-primitives

The short version of how Fulcra actually works, for when you would rather read one page than ten.

Underneath everything else, Fulcra is two ideas. **Data types** are the structured records you can query — the readings, events, and annotations that make up your data. **Files** are versioned uploads, where each write keeps its predecessor rather than overwriting it.

Almost every other skill is built on those two primitives. Once you can create a data type, write records into it, upload a file, and read either back, the rest of the surface stops looking like a product tour and starts looking like variations on things you already understand.

This is the plain introduction to that: no framing, no workflow, just the CLI and what the pieces are.

A good place to start if you prefer learning a system from the bottom rather than the top.
