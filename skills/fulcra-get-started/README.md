# fulcra-get-started

The first thing to read if you have just arrived and none of this means anything yet.

Fulcra gives you one place to keep your real-world data — and, crucially, one place your agents can reach it. The data belongs to you rather than to whichever assistant happens to be holding it, which is what lets you hand the same context to a new agent tomorrow instead of starting over.

This skill walks the setup: connecting your account, seeing what data you already have, and understanding what the environment can do before you commit to any particular workflow.

It is deliberately the wide view. Once you know the shape of things, the other skills go deep — `fulcra-primitives` for how the pieces actually work, `fulcra-ingest` for bringing in exports from services you already use, `fulcra-dashboard` for looking at what you have.

Start here, then leave.
